# 性能与验收记录 / Performance and verification

2026-09-22，v1.11.0 发布前快照（测量时为 Unreleased）。本报告保留当时的环境、版本和实际测量，不代表所有改进建议已完成。

## 已实现

- 保存：UI 线程只捕获脱离可变对象的工作区快照；单个后台写入者合并待处理请求，串行序列化并安全提交。退出等待导入、执行和最后一次保存；失败时保留窗口及旧文件。未恢复旧队列与主动清空当前队列继续分别处理。
- 进度：每 100 ms 合并运行事件；终态同步应用，迟到运行事件不会覆盖终态。增量维护总进度；只有筛选相关变化刷新队列。
- 参数变化：缓存任务数量、首项、失败标记和源大小分布，保留逐文件取整的估算规则；共享策略在预览首项、保存及执行时展开。编码策略未作调整。
- 执行：UI 线程冻结输入，后台启动处理；事件映射回原任务，历史使用冻结参数。系统通知的进程启动也在后台。
- 队列：连续增删使用范围通知，大幅重排使用一次范围 Replace；不发 Reset，保留任务身份、状态及无变化时的控件容器。列表选择与当前编辑任务一致，大队列可逐个移除。
- 缓存：按路径、长度及修改时间校验的 512 条 LRU，逐条淘汰。
- 组合结构：`ParameterEditorViewModel`、`QueuePanelViewModel`、`OutputSettingsViewModel` 持有各自状态。`TaskEditorState` 分离显示值与实际编码参数；保存、应用到全部及预设转换集中，保持旧工作区 JSON 兼容。可替换服务支持构造注入。
- 布局：1180 DIP 起任务与参数并排且独立滚动；窄窗口单列。预设/编码选项靠近参数，去除重复 CRF 开关，应用到全部显示数量。收紧常显命令预览，使用主题警告色，先显示本次结果计数与输出入口，再展开详情/历史。
- 修复恢复的缺失独立文件仍可能进入执行/重试的问题，并避免图片质量显示视频码率警告。

## 测量方法

Windows 11（10.0.26200），.NET SDK 10.0.400 / .NET 8.0.30，FFmpeg/ffprobe 8.1.1；Release 构建，实际桌面 RenderScaling 为 1.25。全部配置、工具目录、日志和合成媒体隔离在 `TestResults`，未使用或清理真实用户媒体。

基线使用隔离 worktree 的 `468b36f`（与本轮起始代码忽略换行后的内容一致），运行相同的性能场景；旧版本不支持的新行为断言仅在新版本运行。每次生成 1,000 个 64×64 PNG；实际编码场景选其中 32 个。纯集合测试另测 10,000 项，不能当作真实万文件窗口检查。

- `FFGUITOOL_REQUIRE_FFMPEG=1`：Debug、Release 各 62 项通过，0 失败、0 跳过。包含旧输出保护、取消清理、失败继续、冲突、参数快照、两遍编码、图片超限、流复制、缓存及试压等既有回归，以及本轮新增状态/持久化测试。

- 真实 Avalonia 窗口：760×560、960×800、1360×900；中英文 × 浅深主题；125% 实际缩放。检查了虚拟化、无变化容器保留、选择一致性、搜索/排序/失败筛选、扫描取消/重扫、独立/共享设置、预设目标、应用设置隔离、旧队列未恢复时保存、缺失文件、清空后重新创建 ViewModel、最终保存和终态顺序。

## 后续工作及未验证范围

- 组合式重构尚未覆盖所有参数联动、媒体估算、预设与历史、执行状态；它们仍有主 ViewModel 协调代码。复杂参数 View、导入和媒体摘要尚未全部拆成独立组件。当前作用范围提示位于参数顶部，还不是滚动过程中的固定栏。
- SetupWindow 的工具配置拆分、GPU 读取统一、PreviewWindow 的缩放交互未实施；窗口尺寸变化的多层失效逻辑保留，尚未单独测量拖动布局成本。
- 未实际验证 macOS/Linux、100%/150%/200% 缩放、跨屏缩放切换、真实硬件编码、大型真实媒体或真实万文件窗口。千文件合成导入不等于大型媒体探测。
- 重启恢复检查是重新创建 ViewModel 并重新读盘；尚未自动化整个进程的崩溃/断电/重启故障注入。后台写盘测试覆盖模拟失败、旧文件保护、合并、顺序和重试，但不是磁盘硬件故障验证。
- 暂无统计学重复采样或长时间内存测试；当前数据只用于确认热点与回归，不作跨机器性能承诺。

## Reproduction (English)

Run the desktop runner from `docs/DEVELOPMENT.md` in Release with FFmpeg available. It creates synthetic files and isolates all app data. The results above are single-run timings, include frame/debounce waits where stated, and report end-of-scenario memory rather than peaks. Full FFmpeg-required regressions pass in both configurations; platform, GPU and additional DPI coverage remain outstanding. View-model decomposition is incremental, not complete.
