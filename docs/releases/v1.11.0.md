# FFGUITool v1.11.0

发布日期 / Release date: 2026-09-28

## 中文

本版改善大批量任务的响应、工作区保存与恢复，以及宽窄窗口下的操作布局。

### 主要更新

- 工作区使用独立快照在后台串行保存，合并待处理保存请求；退出等待最终保存，失败时保留窗口及旧文件。
- 运行进度按 100 ms 合并并增量汇总；执行前冻结参数，避免后续界面修改影响已启动任务。
- 大幅队列重排使用范围更新，保留任务身份与选择；512 条媒体缓存改为 LRU 逐条淘汰。
- 1180 DIP 起任务与参数并排显示，窄窗口恢复单列；列表支持选择编辑、逐个移除，结果区优先展示计数和输出入口。
- 修复恢复队列覆盖参数、共享文件夹丢失比例、图片质量目标显示错误，以及滑块立即应用到全部遗漏最新值的问题。
- 修复切换语言改变参数和任务状态、缺失文件失败状态不一致的问题；继续兼容 v1 工作区 JSON。
- 开发与主线 CI 加入 Windows 工作区恢复场景；发布流程校验标签与版本一致，并附带本版说明。

### 下载与升级

- Windows：x64、x86、ARM64，选择 `Installer.exe` 或 `Portable.zip`。
- macOS：Intel、Apple Silicon，选择 `Installer.dmg` 或 `Portable.zip`。
- Linux：x64、ARM64，选择 `Portable.zip`。
- 从 v1.10.0 升级可继续使用现有预设和工作区；恢复未完成任务会从头执行，不是断点续传。
- 仍需配置 FFmpeg，建议同时提供 ffprobe；ExifTool 可选。图片与视频/音频按模式筛选，尚不支持混合类型统一队列。

### 验证范围

功能提交已通过 Windows/macOS/Linux 的 Debug、Release 自动化检查；本地两种配置各 62 项通过，无跳过。真实 Windows 窗口检查覆盖 125% 缩放、中英文、浅深主题、三种窗口尺寸和千张合成图片。其他桌面平台、额外 DPI、真实 GPU 编码及各架构安装器的实机验收尚未全部覆盖。性能数据是单次小型合成样本，不作跨机器承诺。

## English

This release improves large-queue responsiveness, workspace saving and recovery, and layouts for wide and narrow windows.

### Highlights

- Save detached workspace snapshots through one background writer, coalesce pending requests, and await the final save before exit.
- Coalesce running progress every 100 ms and update totals incrementally; freeze encoding settings before background execution.
- Apply large queue reorderings with range updates while retaining task identity and selection; keep recently used media in a bounded 512-entry LRU cache.
- Display tasks beside settings from 1180 DIP, with a single column for narrow windows; expose per-file removal and clearer result actions.
- Fix saved parameters being overwritten on recovery, lost folder ratios, incorrect image-goal selection, and stale slider values when applying settings to all files.
- Preserve parameters and task states when changing languages and retain missing-input failures. Version 1 workspace JSON remains compatible.
- Add Windows workspace recovery checks to CI and validate release tags against project metadata.

### Packages and compatibility

Windows packages support x64/x86/ARM64, macOS packages support Intel/Apple Silicon, and Linux packages support x64/ARM64. Existing v1.10.0 presets and workspaces remain usable; restored unfinished jobs restart from the beginning. FFmpeg is required, ffprobe is recommended, and ExifTool is optional. Image and video/audio queues remain separated by mode.

### Verification scope

The feature commit passed Debug/Release automation on Windows, macOS and Linux. Local FFmpeg-required tests passed in both configurations (62 each, no skips). Actual Windows UI checks covered 125% scaling, both languages/themes, three window sizes and synthetic 1,000-image queues. Additional desktop/DPI, real GPU and installer-device coverage remains incomplete; single-run synthetic timings are not cross-machine guarantees.
